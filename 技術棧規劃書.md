## 6. 非同步任務與訊息

### 6.1 Celery 設定
```python
# celery_app.py
from celery import Celery

app = Celery(
    'ai_wall',
    broker='redis://localhost:6379/0',
    backend='redis://localhost:6379/1',
)

app.conf.update(
    task_serializer='msgpack',         # 比 JSON 快 3x
    result_serializer='msgpack',
    timezone='Asia/Taipei',
    worker_prefetch_multiplier=1,      # GPU 任務避免搶
    task_acks_late=True,               # 失敗重排程
    task_time_limit=600,               # 10 分鐘 hard
    task_soft_time_limit=540,          # 9 分鐘 soft
    task_routes={
        'tasks.cv.*':       {'queue': 'gpu'},
        'tasks.ga.*':       {'queue': 'cpu_heavy'},
        'tasks.pdf.*':      {'queue': 'cpu_light'},
        'tasks.email.*':    {'queue': 'io'},
    },
)
```

### 6.2 Worker 配置
| Queue | Worker 類型 | concurrency | 用途 |
|-------|------------|------------|------|
| `gpu` | GPU 節點 | 1 | SAM 推論 |
| `cpu_heavy` | CPU 多核 | 4 | GA 最佳化 |
| `cpu_light` | CPU | 8 | PDF、報表 |
| `io` | CPU | 16 | Email、Webhook |

### 6.3 WebSocket 進度推送
```python
@app.task(bind=True)
def run_ga_task(self, project_id, params):
    def progress_cb(gen, coverage):
        # 推送到 Redis pub/sub
        redis.publish(
            f"task:{self.request.id}",
            json.dumps({'progress': gen/total*100, 'coverage': coverage})
        )
    result = optimize_ap_placement_auto(..., progress_cb=progress_cb)
    return result

# FastAPI WebSocket 端點
@app.websocket("/api/v1/tasks/{task_id}/stream")
async def task_stream(websocket, task_id):
    pubsub = redis.pubsub()
    await pubsub.subscribe(f"task:{task_id}")
    async for msg in pubsub.listen():
        await websocket.send_json(msg['data'])
```

## 7. 認證與權限

### 7.1 認證流程
```
1. POST /auth/register → 建立 user, 回傳 JWT (15 min)
2. POST /auth/login    → 驗證, 回傳 access_token + refresh_token
3. POST /auth/refresh  → access 過期時換新 token
4. POST /auth/logout   → 加入 Redis blacklist (JWT jti)
```

### 7.2 JWT 結構
```json
{
  "sub": "user_uuid",
  "org": "org_uuid",
  "plan": "pro",
  "roles": ["editor"],
  "iat": 1700000000,
  "exp": 1700015400,
  "jti": "unique_token_id"
}
```

### 7.3 權限模型（RBAC）
| Role | Project Read | Project Write | Delete | Admin |
|------|-------------|--------------|--------|-------|
| viewer | ✓ | – | – | – |
| editor | ✓ | ✓ | – | – |
| admin | ✓ | ✓ | ✓ | – |
| owner | ✓ | ✓ | ✓ | ✓ |

### 7.4 SSO（Phase 2+）
| Provider | Protocol |
|----------|---------|
| Google Workspace | OAuth2 + OIDC |
| Microsoft 365 | OAuth2 + OIDC |

### 13.2 GA 最佳化流程
```
1. User clicks "Auto Place APs" with target=90%, num=0 (auto)
2. Frontend → POST /projects/{id}/optimize { target_coverage: 0.9 }
3. FastAPI 驗證 + 加入 Celery queue → 回傳 task_id
4. Frontend 開 WebSocket /tasks/{task_id}/stream
5. Celery worker:
   a. 讀 walls from DB → convert to numpy arrays
   b. capacity_min = ceil(area / 120)
   c. 從 capacity_min 到 16, 跑 GA
   d. 每 5 代 publish progress
   e. 找到 ≥90% → 寫入 access_points 表
6. Frontend 收 'done' → GET /projects/{id}/aps → 渲染
```

### 14.2 Pydantic Schema
```python
# schemas/optimize.py
from pydantic import BaseModel, Field
from enum import Enum
from uuid import UUID

class Algorithm(str, Enum):
    ga = "ga"
    grid = "grid"
    manual = "manual"

class OptimizeRequest(BaseModel):
    algorithm: Algorithm = Algorithm.ga
    target_coverage: float = Field(0.9, ge=0.5, le=1.0)
    num_aps: int = Field(0, ge=0, le=50)
    sqm_per_ap: float = Field(120, ge=30, le=500)

class OptimizeResponse(BaseModel):
    task_id: UUID
    status_url: str
    stream_url: str
```
